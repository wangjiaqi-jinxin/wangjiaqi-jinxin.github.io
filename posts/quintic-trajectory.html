离散五次多项式轨迹融合：从 PVA 边界到平滑过渡

当机器人需要在已有轨迹中切换目标时，重点不是简单连接两个位置，而是让位置、速度与加速度都自然地过渡。

问题背景

在离散控制周期中，如果直接从旧轨迹跳转到新轨迹，位置可能连续，但速度和加速度往往会出现突变。这会带来明显的跟踪误差，甚至触发动力学限制。

一个实用的策略是在切换点和新目标之间插入一段短过渡轨迹。过渡轨迹需要满足起点和终点的 PVA（position、velocity、acceleration）状态。

PVA 边界

设过渡总时长为 T，起点状态为 (p₀, v₀, a₀)，终点状态为 (p₁, v₁, a₁)。六个边界约束恰好对应一个五次多项式的六个系数。

p(t) = c₀ + c₁t + c₂t² + c₃t³ + c₄t⁴ + c₅t⁵

先由起点直接确定 c₀、c₁、c₂，再将终点位置、速度和加速度代入求解剩余三个系数。实际工程中，使用归一化时间 τ = t / T 通常能让数值计算更稳定。

五次多项式为什么合适

三次多项式可以保证位置和速度连续，但无法同时约束两端加速度。五次多项式则能提供二阶连续性，适合对加速度平滑性有要求的伺服轨迹。

不过，连续不代表一定可执行。生成后还应按控制周期离散采样，并检查速度、加速度与加加速度是否超过系统限制。

C++ 实现

下面的接口展示了构造函数的职责：输入两端 PVA 状态和时长，输出多项式系数。系数求解可独立封装，便于测试不同边界条件。

struct PvaState { double p, v, a; };

bool buildQuinticTransition(
    const PvaState& start,
    const PvaState& goal,
    double duration,
    QuinticCoefficients& out)
{
    if (duration <= 0.0) return false;

    // c0, c1, c2 come from the start PVA state.
    out.c0 = start.p;
    out.c1 = start.v;
    out.c2 = 0.5 * start.a;
    // Solve c3..c5 using the goal PVA constraints.
    return solveRemainingCoefficients(start, goal, duration, out);
}

在真正接入控制器前，建议先用固定控制周期采样，验证端点误差、最大速度与最大加速度。这比只检查系数本身更接近最终运行条件。

小结

五次多项式的价值在于把“平滑切换”转成一组明确的边界约束。它不是完整的轨迹规划器，但作为局部融合段，足够直接、可解释，也容易和现有离散控制系统结合。
